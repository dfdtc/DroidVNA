# DroidVNA 0.7.1-beta

> English: [docs/en/release-notes/0.7.1-beta.md](../en/release-notes/0.7.1-beta.md)

在迹线标记旁新增一组**分析工具**：带宽搜索、XdB 搜索和 DTF（时域 / 故障距离）。
三个功能共用同一套标记和迹线数据，不改变现有的扫描、校准和导出路径。

> **这是 Beta 版。** 分析工具已在演示模式和 JVM 单元测试中验证，但**尚未在真实 VNA、已知长度
> 电缆或桌面版 LibreVNA-GUI 上校准 DTF 距离精度**。计量级用途请继续使用桌面版。

## 新增

### 分析入口

测量页的标记按钮组（`＋ 标记` / `峰值` / `谷值` / `清除`）旁新增「分析 ▾」入口，出现在：

- 收起状态的顶部控件行
- 图表下方的标记栏
- 大屏侧栏「迹线」卡片

点开后是二级菜单：**带宽搜索 / XdB 搜索 / DTF**。三个功能都在底部面板中配置参数并执行，
分析生成的标记会在下一次分析时自动替换；手动标记和自定义游标不受影响。

### 带宽搜索

- 在指定 S 参数迹线上选择**峰值**或**自定义游标**（已有标记）作为 0 dB 参考。
- 按用户定义的 **-X dB**（默认 -3 dB）向两侧搜索边沿。
- 交叉点在相邻采样点之间做 dB 域线性插值，不强制吸附到最近的采样点。
- 搜索完成后把两个边沿作为标记加回图上，并显示参考电平、目标电平、左右边沿、带宽和中心频率。
- 未完成扫描留下的 NaN 间隙会终止该方向的搜索，不会跨过空洞“造”出一个边沿。

### XdB 搜索

- 带宽搜索的通用版本：可只搜索参考的**左侧 / 右侧 / 双侧**。
- 带宽搜索直接复用双侧 XdB 逻辑；单侧搜索只添加找到的那个边沿。
- 结果会明确提示「只找到左侧/右侧 1 个边沿」或「未找到交叉点」。

### DTF（时域 / 故障距离）

- 对 **S11 / S22** 复数反射数据做加窗 IFFT。IFFT 使用已有的 Apache Commons Math
  `FastFourierTransformer`，没有手写 FFT。
- 频域数据先重采样到均匀栅格，因此对数扫描也能处理；再补零、加窗、反变换。
- 支持**矩形 / Hann / Hamming / Blackman** 窗、IFFT 补零插值（1×/2×/4×/8×）、
  速度因子（默认 0.66）、缆损补偿、峰值门限和显示距离上限。
- 距离换算：`d = c · VF · t / 2`；距离分辨率：`c · VF / (2 · span)`。
- 结果包含距离域曲线（相对幅度，0 dB = 最强反射）和按距离排序的故障点列表
  （距离、往返时延、相对幅度），并显示最大距离、分辨率、FFT 点数、窗函数和速度因子。
- 全范围显示时会裁掉最远端的几个分辨率单元：IFFT 是循环卷积，0 m 反射会卷绕到记录末端，
  不处理就会被误报成最远端的第二个故障。面板会注明该区域已从故障表排除。
- 计算使用最近一次**完整扫描**，半帧扫描不会悄悄改变频率跨度。

## 实现与测试

- 新增 `model/analysis` 模块：
  - `XdbSearch.kt`：峰值/游标参考、左右/双侧搜索、dB 域插值、NaN 间隙处理。
  - `Dtf.kt`：均匀重采样、窗函数、补零 IFFT、距离换算、峰值检测与卷绕保护。
- 新增 UI：
  - `ui/components/AnalysisMenu.kt`：标记旁的二级菜单。
  - `ui/sheets/AnalysisSheet.kt`：带宽 / XdB / DTF 底部面板。
  - `ui/chart/DtfChart.kt`：距离域曲线。
- 新增 15 个 JVM 单元测试：带宽/XdB 搜索 7 个、DTF 7 个、英文 UI 翻译 1 个。
  当前共 **67 个 JVM 单元测试全部通过**。

## 验证说明

- **67 个 JVM 单元测试全部通过**；分析测试覆盖：双侧/单侧搜索、边沿插值、
  未完成扫描、无效 X 值、合成反射距离、速度因子缩放、对数扫描重采样、峰值门限、
  显示距离截断、0 m 卷绕保护。
- **演示模式验证**（Xiaomi Pad，Android 17，演示 DUT 为 1.75–2.65 GHz 带通）：
  - 带宽搜索得到参考峰值 2.3125 GHz、左右边沿 1.8157 / 2.5889 GHz，
    图上出现两个边沿标记；再次搜索会替换旧的分析标记。
  - XdB 左侧搜索只添加左边沿，并提示「只找到左侧 1 个边沿」。
  - DTF 在演示 S11 上得到约 15.7 m 最大距离、4.0 cm 分辨率、2048 点 FFT；
    距离域曲线、故障点表和 0 m 卷绕说明正常。
  - 中文 / English 界面下的分析菜单、面板和结果文案均完整翻译。
- **本版仍未验证**：DTF 与已知长度电缆 / 故障点的距离精度对照；真实 VNA 上的带宽 / XdB 搜索；
  LibreVNA 官方硬件。
