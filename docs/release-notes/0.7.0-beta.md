# DroidVNA 0.7.0-beta

完整的 **12 项双端口 SOLT 校准**（对应 [issue #2](https://github.com/dfdtc/DroidVNA/issues/2)），
隔离项可单独补测/替换，未校准频段会明确提示。

> **这是 Beta 版。** 12 项 SOLT 的 E-Cal 自动流程已在真机（B60 + ECB-60）上跑通并成功应用，
> 但**绝对精度尚未与桌面版 / 已知 DUT 对照**，**手动 SOLT 也尚未上机**（缺机械校准件）。
> 计量级用途请继续使用桌面版 LibreVNA-GUI。详见文末「验证说明」。

## 新增

### 完整 12 项 SOLT

此前的校准只做 1 端口 SOL（方向性、源匹配、反射跟踪）加 THRU 归一化。THRU 归一化在数学上
无法扣除端口失配造成的传输误差——THRU 期间 DUT 被换成直通，直通的 S11/S22 接近 0，分母里的
失配项几乎观察不到；接上真实 DUT 后，S21/S12 就会有系统性偏差，端口反射越大越明显。

现在会解出全部 12 项误差模型，并按多端口公式 `S = B·A⁻¹` 逐点修正：

| 误差项 | 每端口/方向 |
| --- | --- |
| 方向性 Directivity、源匹配 Source Match、反射跟踪 Reflection Tracking | 每端口 |
| 接收机匹配 Receiver Match、传输跟踪 Transmission Tracking、隔离 Isolation | 每方向 |

- **手动 SOLT**：校准页新增「双端口 SOLT」分区，带前置条件清单、THRU 延迟（ps）输入和
  「计算并应用完整 SOLT」按钮。
- **E-Cal 全自动**：双端口校准件依次完成两端 Open/Short/Load → THRU，然后一次性解出完整模型。
- **`.cal` 导入**：含两端口的 1 端口测量与 THRU 时直接重建完整 12 项，并读取其中的 Isolation；
  数据不足时仍退回 1 端口 SOL + THRU。
- **演示模式**改用真实 12 项误差模型，没有硬件也能完整跑通 SOLT。

### 隔离项：可选、可单独补测

- E-Cal 的隔离测量改成**可选勾选框，默认关闭**。ECB-60 这类双端口电子校准件的隔离通路本身
  较差，它测出的串扰往往不如两个机械 50 Ω 负载；默认关闭，需要时再打开。
- 隔离项可以**单独替换**，不用重做 Open/Short/Load/THRU：两端各接 50 Ω 负载捕获一次，点
  「只用本次捕获更新隔离项」。传输跟踪是按 `(THRU S21 − 隔离)` 求出的，所以校准快照会一并
  保存 THRU 的实测值与理想值，替换是**精确重算**而不是近似修正。

### 未校准频段提示

扫描范围超出已校准频段时，测量页「校准」卡片和校准页状态卡都会提示
「测量范围覆盖未校准频段」并给出已校准频段。此前带外点是静默跳过、界面毫无提示。

## 变更

- 1 端口 SOL 的误差项改为与 LibreVNA-GUI `computeOSL` 相同的闭式解，结果与桌面版一致。
- 新增依赖 Apache Commons Math 3.6.1：复数 2×2 求解与矩阵求逆用 `FieldLUDecomposition`，
  不再手写高斯消元。
- 完整 SOLT 优先于 1 端口 SOL / THRU 归一化应用，两者不会重复修正。
- 校准快照格式升到 version 3（新增 `solt` 段，含 THRU 原始数据）；旧文件仍可载入。

## 修复（独立审查发现）

- **手工 SOLT 现在校验各次捕获的扫描范围**：此前 THRU / 端口 2 / 隔离会重采样到端口 1 的
  网格，而插值对带外点是**静默钳位到端点值**，改动过扫描设置后解出的误差项会错得没有症状。
  `.cal` 导入的频段覆盖也一并加了检查。
- **标准件模型在 0 Hz 不再产生 NaN**（`Through`、参数化 `Open`、带并联电容的 `Load`），
  起始频率为 0 Hz 时不再表现为「SOLT 无解」。
- **被截断的校准快照不再能越界崩溃**（校验系数数组长度与频率网格一致）。
- **单频点校准被拒绝**；**标准件过于接近时**不再产出离谱系数，而是判为无解。
- 手工 THRU 归一化与 `.cal` 导入的语义统一为 `实测/理想`。

## 验证说明

- 工具链：Gradle 8.14.4、AGP 8.13.2、Kotlin 2.4.21，compileSdk / targetSdk 36。
- **48 个 JVM 单元测试全部通过**。其中 12 项模型的正确性用两种独立方式交叉验证：
  - 生产代码的正向模型与**独立的信号流图推导**逐点吻合（1e-12）；
  - 修正后的标准件回到理想值（+1 / −1 / 理想直通），这是不引用模型的地面真值检查。
- **真机验证**（Xiaomi Pad，Android 17 + Harogic B60 FW 1.8.6 + ECB-60 FW 0.3.2）：
  - 12 项 SOLT 的 E-Cal 自动流程在 401 点 / 500 MHz–3 GHz 下解算并应用成功，
    测量页显示 `采集中 CAL`，校准卡显示「已应用 · 12 项 SOLT · P1 SOL · P2 SOL」，无崩溃；
  - 隔离勾选框两种设置都跑通（含隔离测量 / 未做隔离测量），默认关闭符合预期；
  - 校准后 E-Cal 置 NONE（等效开路）时 S11 ≈ 0 dB、S21 在 −80…−100 dB 噪底，物理合理；
  - 「测量范围覆盖未校准频段」提示按预期出现。
- **本版仍未验证**：与桌面版 / 已知 DUT 的幅度相位精度对照（需要机械校准件与参考滤波器），
  手动 SOLT 全流程（需要人工更换标准件），以及 LibreVNA 官方硬件。
