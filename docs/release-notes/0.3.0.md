# LibreVNA Mobile 0.3.0

> English: [docs/en/release-notes/0.3.0.md](../en/release-notes/0.3.0.md)

首个公开版本：把 LibreVNA / Harogic B60 的实时双端口测量、触摸图表、SOL 校准与导出带到 Android 平板和手机。

## 亮点

- **原生 USB Host，无 PC**：直接通过 OTG 访问 VNA 的 vendor-specific bulk 端点，协议 v14。
- **实时双端口扫描**：S11 / S21 / S12 / S22，低 IFBW 下渐进出点、环形滚动刷新。
- **触摸优先图表**：双指缩放/平移、十字光标、可拖动标记、峰值/谷值、dB/相位/VSWR/Smith。
- **1 端口 SOL + THRU**：按设备序列号隔离保存，重启后仍生效。
- **LibreVNA-GUI `.cal` 导入**：支持 Touchstone 和参数化 calkit，重建 SOL + THRU 后立即应用。
- **LibreCAL / ECB-60 电子校准**：USB SCPI 读取系数，显示温度/稳定状态，自动完成 2 端口 SOL + THRU。
- **导出**：Touchstone `.s2p` / `.s1p`、CSV，保存到 `Download/LibreVNA` 或系统分享。
- **演示模式**：没有硬件也能体验完整校准流程。

## 安装

```bash
adb install -r LibreVNA-Mobile-0.3.0-debug.apk
```

- 要求 Android 8.0（API 26）及以上，支持 USB Host / OTG。
- 该 APK 为 debug 签名，仅供测试；正式分发请使用自己的 release keystore。
- SHA-256：`403AFC857E5156A87FE0DB7FCBC0B707CCBA157642289674E41460D6AC282357`

小米/HyperOS 如提示 `INSTALL_FAILED_USER_RESTRICTED`，请使用：

```bash
adb push LibreVNA-Mobile-0.3.0-debug.apk /data/local/tmp/librevna.apk
adb shell pm install -r -t /data/local/tmp/librevna.apk
```

## 已验证

- Xiaomi Pad（Android 17）+ Harogic B60（FW 1.8.6）：401 点 / 75 kHz 连续扫描约 19–20 次/秒；15 Hz / 101 点与 1 kHz / 401 点下渐进绘制、环形滚动正常。
- Harogic ECB-60（FW 0.3.2）：FACTORY 系数加载、自动 2 端口 SOL + THRU、CAL 生效。
- VNStudio 导出的真实 `.cal`：Touchstone 与纯参数化 calkit 两条路径均导入成功。
- 21 个 JVM 单元测试全部通过。

## 已知限制

- 校准模型为 1 端口 SOL + THRU，不包含完整 12 项双端口 SOLT 误差项；`.cal` 导入和 E-Cal 自动校准同样只使用该子集。
- E-Cal 固定 VNA P1/P2 ↔ Cal P1/P2 映射，需要带外部供电的 OTG Hub。
- 未实现固件更新、信号源、频谱分析、SCPI 服务器和独立 Touchstone 校准套件导入。
- 图表超过 1001 点未做性能优化。
- LibreVNA 官方硬件尚未上机实测。
