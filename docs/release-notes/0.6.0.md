# DroidVNA 0.6.0

小屏横屏 Smith 圆图的触摸闪退修复，Smith 双指缩放/平移，以及在圆图上操作标记的迹线频率滑条。

## 修复

### 小屏横屏触摸 Smith 圆图导致闪退

圆图的十字线读数框在没有空间时会崩溃：

```
java.lang.IllegalArgumentException: Cannot coerce value to an empty range:
maximum 816.25 is less than minimum 826.75.
  at com.droidvna.app.ui.chart.VnaChartKt.drawTooltip
  at com.droidvna.app.ui.chart.VnaChartKt.drawSmithCrosshair
```

读数框（`|Γ| 0.045 ∠31°` / `VSWR 1.09`）约 320 px 宽，而小屏横屏下圆图绘图区只有约 278 px。
用于把读数框夹在绘图区内的 `coerceIn` 于是收到"上限 < 下限"的空区间，在绘制阶段抛出异常，
整个应用闪退。

修复：读数框宽度上限被夹到绘图区内；钳制区间无效时退回左对齐。任何图表尺寸都不会再落空。

### Smith 圆图双指缩放、双指平移不生效

旧代码在双指分支里直接跳过 Smith 模式：

```kotlin
if (modeNow != ChartMode.SMITH) { /* 缩放/平移 */ }
```

所以 Smith 模式下双指能被识别却什么也不做，视图被写死为整圆。

现在 Smith 视图有独立的视口状态（中心 Γ + 窗口半径，`SmithView`）：

- 双指张合缩放 **1×～50×**，双指拖动平移，内容跟手；
- 网格随缩放重绘（电阻圆/电抗圆/实轴标签都按视口重新计算）；
- 拖动受限，Γ=0 圆心不会被拖出画面；
- 双击图表、「复位」按钮都能回到整圆；
- 曲线与标记都映射到新视口，并裁剪到圆图外框。

### Smith 圆图偏小

`smithBounds` 固定留 48 dp 边距，小屏横屏下圆图被压缩到约 278 px。改为按比例留边
（12 dp 起、约 6%），各尺寸下圆图都明显变大。

## 变更

### 右上角按钮

那个图标（`CenterFocusStrong`）一直是 **复位视图**，不是全屏键。它看起来"从没生效"是因为：

1. 它是复位操作，只在视图被缩放过之后才有事可做；
2. Smith 模式此前被锁死为整圆，所以在那里按它必然没有变化；
3. 按钮着色是固定的灰色，即使复位成功也看不出变化。

现在：视图偏离默认时按钮变为主题青色，复位后回到灰色；Smith 模式下的无障碍描述改为
「复位圆图」；放大时右上角显示 `×N` 倍率标签。

## 新增

### 迹线频率滑条

在 Smith 圆图上精确点到细迹线并不容易，尤其在小屏上。现在只要有标记，圆图底部就会出现：

```
M1  迹线频率 ────────●──────── 1.4188 GHz
```

- 拖动滑块让选中标记沿扫频移动，并吸附到最近的实测点；
- 底部标记卡可点选，选中的卡片高亮，决定滑条控制哪个标记；
- 在圆图上按住标记拖动时，标记跟随手指并按屏幕距离吸附到最近的迹线点。
