# LibreVNA Mobile 0.4.0

双语界面、应用设置与更灵活的图表控制。

## 亮点

- **中文 / English 双语 UI**：右上角齿轮 →「应用设置」→「界面语言」，支持跟随系统 / 中文 / English，
  切换即时生效并持久化。
- **应用设置面板**：语言与关于信息（版本、协议、支持设备、GPL-3.0、上游项目）集中管理。
- **迹线设置面板**：图表上方或「迹线」卡片右侧齿轮打开；首项为**对数频率轴**（1-2-5 刻度），
  设置持久化，后续迹线选项会继续加在这里。
- **Y 轴自动 / 手动**：图表上方新增 `Y auto` / `Y manual` 切换；手动缩放后可一键恢复自动缩放。
- 图表 X 轴的捏合缩放、平移、十字光标和标记均支持对数频率轴。

## 安装

```bash
adb install -r LibreVNA-Mobile-0.4.0-debug.apk
```

- 要求 Android 8.0（API 26）及以上，支持 USB Host / OTG。
- 该 APK 为 debug 签名，仅供测试；正式分发请使用自己的 release keystore。
- 大小：16,845,011 字节
- SHA-256：`4272B311C04CA948793525C606C6AD3896E060E802E81902A0FE70F7828A1705`

小米/HyperOS 如提示 `INSTALL_FAILED_USER_RESTRICTED`，请使用：

```bash
adb push LibreVNA-Mobile-0.4.0-debug.apk /data/local/tmp/librevna.apk
adb shell pm install -r -t /data/local/tmp/librevna.apk
```

- 英文翻译覆盖主要界面与常见消息；极少数底层设备/协议日志可能保留原文。
