# DroidVNA 0.7.4

> English: [docs/en/release-notes/0.7.4.md](../en/release-notes/0.7.4.md)

0.7.4 是 **Smith 圆图交互修复 + 两个实用工具** 的正式版本（去掉 beta 后缀）。

1. 修掉 Smith 圆图「像两个图层」的拖动问题，等电阻圆与等电抗弧现在一起变换。
2. 新增 **Smith 3D 球图**，给放大器调谐用：稳定圆、源/负载牵引这类 `|Γ| > 1` 的曲线在平面圆图上
   无处安放，在球面上可以正常显示。
3. Smith 读数补第二个数（虚部 / 角度），XdB 搜索补 `+X dB` 与「谷值」参考，双标记 Δ 补频率差 ——
   这三条都是天线与放大器调试时最常换算的量。

## 修复

### Smith 圆图：拖动时等电阻圆不跟随

等电阻圆的圆心被写死成控件中线（忽略了 `SmithView.focusIM`），而等电抗弧和迹线走 `gammaToOffset`。
于是竖直拖动时只有迹线与电抗弧在动、电阻圆底图钉在原处，看起来更像两个图层。

现在两族圆都由同一个 `SmithView` 经 `gammaToOffset` 求圆心，缩放/平移后底图与迹线严格同步；
顺带把等电抗圆的圆心公式修正为数学正确的 Γ 圆心 `(1, 1/x)`（原先写成 `-1/x`，只因为电抗栅格
正负对称才一直没被发现）。圆图的缩放/平移仍然只用双指，单指始终是十字线读数。

### `SweepSettings` 包长按设备选择，不再影响其他设备

0.7.2-beta 为了让 B60 拿到第 32 字节 `extTrigger`，对所有设备都发了 32 字节。现在改为
`Protocol.encodeSweepSettings(config, standby, legacy31 = true)`：

| 设备 | 包长 |
| --- | --- |
| LibreVNA 官方硬件、未知 LibreVNA 兼容设备（默认） | 31 字节（上游标准） |
| Harogic B60（驱动显式传 `legacy31 = false`） | 32 字节（含 `extTrigger`） |

B60 的行为不变（仍显式写 `extTrigger = 0`），其他设备不再被多塞一个字节。

## 新增

### Smith 3D 球图（`ChartMode.SMITH_3D`）

把反射系数按黎曼球投影到单位球面：`|Γ| < 1` 在南半球、`|Γ| > 1` 在北半球，赤道是 `|Γ| = 1` 圆。

- 单指拖动旋转（yaw/pitch），双指缩放，双击复位，复位按钮与 `×N` 倍率沿用圆图交互；
- 俯仰是**整圈旋转**而不是上下限 —— 越过极点继续拖，就能把 `|Γ| < 1` 的南半球正面转到眼前；
- 线框与迹线按深度分成前后两半，背面半透明，标记按深度淡出；
- 球面数学放在独立文件 `ui/chart/SmithSphereMath.kt`（不依赖 Compose，可单测）。

### Smith 读数：虚部 / 角度

标记与十字线原先只显示 `|Γ|`，无法区分同一个圆上的不同点。现在默认追加 **虚部**
（`S11 |Γ| 0.184  Im +0.082`，带符号，能看出点在实轴哪一侧），可在「迹线设置 → Smith 读数」
切成 **角度**（`∠26.6°`）。这是同一个点的两种表示，只影响显示。

### XdB / 带宽搜索：`+X dB` 与「谷值」参考

- 搜索深度框前多了 `±` 切换按钮：`−` 往参考电平下方找（滤波器通带衰减），`+` 往上找（天线带宽）；
- 快捷 chip 去掉负号（1 / 3 / 6 / 10 / 20 dB），方向由按钮决定；
- 参考新增 **谷值**：天线带宽要从 `|S11|` 的谷底向两侧上搜，峰值参考下按 `+` 永远找不到交叉点。
  切到 `+` 会自动把参考换成谷值，切回 `−` 自动换回峰值；
- 结果卡多一行「偏移 +3.0 dB」，状态栏与提示消息也用带符号的形式（「未找到 +3.0 dB 交叉点」）。

### 双标记 Δ：补频率差

打开 `Δ` 后，除各迹线的幅度差外多一行 `Δf +768.750 MHz`。两个标记都取「实际读数所在的扫频点」
（与标记卡片同一套取点），带符号表示哪个标记频率更高；暂停扫描或还没出数据时也能看。

## 验证

- **93 个 JVM 单元测试全部通过**。本版新增：谷值参考、`+X dB` 双向搜索、默认方向仍为 `−`、
  两种 Smith 读数格式、黎曼球映射（赤道/南北半球/极点/整圈旋转）、以及 `smithReadout` 的设置持久化往返。
- **真机**（Xiaomi Pad，Android 17）：演示模式下逐项确认
  - Smith 标记显示 `|Γ| 0.184 Im +0.082`，切到角度后同一标记显示 `∠26.6°`；
  - 球图单指竖直拖动越过极点后南半球转到正面，极点标签随之换边；
  - `−` 切到 `+` 时参考自动从峰值变谷值，S11 谷值（2.0875 GHz / −18.0 dB）上做 `+3 dB` 双侧搜索
    得到边沿 2.0089 / 2.1828 GHz、带宽 173.88 MHz、中心 2.0958 GHz；
  - 双标记 Δ 显示 `Δf +768.750 MHz`，与两张标记卡（1.8188 / 2.5875 GHz）一致。
- **尚未验证**：DTF 距离精度与真实电缆对照、LibreVNA 官方硬件的 31 字节标准包实测。

## 升级说明

- `versionCode` 由 12 升到 **13**（0.7.2-beta 是 11；中间的 0.7.3-beta 只做过内部构建，没有公开）。
- 协议仍是 **v14**，无需升级固件；校准数据格式不变，已保存的校准可继续使用。
- 同一签名可覆盖安装。
