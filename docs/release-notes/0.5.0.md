# DroidVNA 0.5.0

> English: [docs/en/release-notes/0.5.0.md](../en/release-notes/0.5.0.md)

界面重排（统一右上角菜单 + 背景水印 + 可收起控件 + 横屏竖排采集栏），以及设置与校准的自动记忆。

## 新增

### 界面

- **右上角统一菜单**：测量页不再有标题栏。扫描设置、迹线设置、校准、导出、设备、应用设置、
  收起控件全部收进右上角唯一的 `⋮`。迹线图因此可以使用上下全部高度。
- **背景水印**：`DroidVNA` 与副标题以半透明水印画在迹线图背景里，位于网格和迹线之下。
  应用设置 →「界面 → 关闭应用水印」可以整层关闭，关闭后背景是纯色。
- **可收起控件**：迹线选择/模式/Y 轴控件行，以及大屏右侧、横屏左侧的采集卡片列都能收起；
  菜单项、控件行末尾 `⌃`、采集卡片 `⌃` 三处入口。收起后标记快捷操作仍然保留。
- **手机横屏竖排采集栏**：宽度 ≥ 600 dp 且横向时使用双栏布局，采集控件竖列停靠**左侧**，
  迹线图占右侧；不再是底部横向排列。

### 设置记忆

- 扫描参数（起止频率、点数、IFBW、功率、平均、单/双端口、对数扫描、自动连续扫描）、
  图表模式、迹线参数、Y 轴缩放、对数频率轴、水印开关、标记位置、Δ 标记、控件收起状态、
  界面语言全部自动保存，下次启动原样恢复。
- 「连接后自动连续扫描」可以关闭，改为手动点「开始扫描」。
- 存储：`filesDir/settings.json`，临时文件 + 重命名原子写入，损坏时回退默认值。

### 校准记忆

- SOL / THRU / 电子校准（E-Cal）/ `.cal` 导入的结果在每次变化后立即保存为一份快照
  （`filesDir/calibration.json`），记录设备序列号、来源、系数集名与更新时间。
- 下次启动自动载入并应用，测量页顶部提示「已自动载入上次校准（…）」。
- 应用设置 →「校准记忆」可以查看已保存的校准详情、**停用校准**（保留系数、只看原始数据，
  随时可重新启用）或**忘记已保存的校准**。
- 校准按设备序列号隔离：换一台 VNA 不会把旧设备的校准套上去，切回原设备时仍然恢复。

## 修复

- **设置不落盘**：旧实现用 `snapshotFlow` 观察 `MutableStateFlow`，而后者不是 Compose 快照状态，
  实际只在启动时写过一次文件。现在改为合并所有状态流 + 400 ms 去抖 + 内容比较后写入。
- **release 签名**：`keystore.properties` 支持放在 `android/`、仓库根目录或 `.github/`，
  `storeFile` 的相对路径按 properties 所在目录解析（支持 `../xxx.jks`）。配置存在但无效时
  构建直接失败并给出原因，不会再静默产出 unsigned APK；构建日志打印实际使用的 keystore 与 alias。
- 同时开启 v1 / v2 / v3 签名。

## 验证说明

- 工具链：Gradle 8.14.4、AGP 8.13.2、Kotlin 2.4.21，compileSdk / targetSdk 36。
- 26 个 JVM 单元测试通过（新增设置/校准快照的 JSON 往返、损坏文件回退、跨设备隔离）。
- 实机验证（Xiaomi Pad，Android 17）：
  - 平板横屏双栏布局、右上角菜单、水印、控件收起与展开；
  - 手机横屏（`wm size 1080x2400` + 密度 440 模拟 873×393 dp）确认采集栏竖列在左、图表在右；
  - 收起状态、水印开关、扫描参数在强杀重启后恢复；
  - Harogic B60（FW 1.8.6）连接与连续扫描正常。
- E-Cal 2 端口时序修复仍建议在 VNB-60 + ECB-60 实机复测。
