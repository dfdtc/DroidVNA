# 路线图与已知限制

> English version: [docs/en/ROADMAP.md](en/ROADMAP.md)

本文档记录 DroidVNA 当前的边界与后续方向。与具体操作相关的问题请先看 [故障排查](TROUBLESHOOTING.md)。

## 已知限制

- 没有固件更新、手动控制、信号源、频谱分析、幅度/功率校准、频率校准和 SCPI 服务器。
- 完整 12 项 SOLT 支持双端口（2 端口即全部 12 项）；三端口/四端口设备的扩展未实现。手动 THRU 按理想直通处理，非理想直通请填延迟或改用 E-Cal / `.cal`。
- 双端口电子校准件（如 ECB-60）的隔离通路较差，E-Cal 自带的隔离测量默认关闭；需要隔离修正时建议用两个机械 50 Ω 负载单独补测（校准页支持只替换隔离项）。
- 没有独立的 Touchstone 校准套件文件导入；`.cal` 导入可重建完整 SOLT，但单端口 `.cal` 仍只得到 1 端口 SOL + THRU。
- E-Cal 固定 VNA P1/P2 ↔ Cal P1/P2 映射，不包含自动端口识别；需要带外部供电的 OTG Hub。
- 图表为自绘 Compose Canvas，极大点数（>1001）未做性能优化。
- 仓库内预构建 APK 为 release 构建 + 项目发布密钥；正式分发请配置自己的 release keystore 重新构建（见 [发布流程](RELEASING.md)）。
- 在手机上使用前建议先用演示模式确认布局与操作。
- 英文翻译覆盖主要界面和常见消息；极少数底层设备/协议日志可能保留原文。
- LibreVNA 官方硬件尚未上机实测；完整 SOLT 尚未与桌面版 / 已知 DUT 做绝对精度对照，手动 SOLT 全流程尚未在真机上验证。

## 验证状态

当前版本标记为 **beta** 的原因与实机验证记录见 [测试与验证](TESTING.md) 和 [0.7.0-beta Release Notes](release-notes/0.7.0-beta.md)。

## 后续方向

- 与桌面版 LibreVNA-GUI 及已知 DUT 做幅度/相位精度对照。
- 用机械校准件验证手动 SOLT 全流程。
- LibreVNA 官方硬件上机验证。
- 校准套件文件导入、三/四端口设备扩展、大点数图表性能优化。
- 补充英文翻译覆盖（底层设备/协议日志）。
