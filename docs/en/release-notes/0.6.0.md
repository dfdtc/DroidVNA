# DroidVNA 0.6.0

> [中文版](../../release-notes/0.6.0.md)

Touch-related crash fix for the Smith chart on small landscape screens, Smith chart pinch zoom/pan, and a trace-frequency slider for marker work on the chart.

## Fixes

### Touching the Smith chart on a small landscape screen crashed the app

The chart's crosshair readout box crashed when there was no room for it:

```
java.lang.IllegalArgumentException: Cannot coerce value to an empty range:
maximum 816.25 is less than minimum 826.75.
  at com.droidvna.app.ui.chart.VnaChartKt.drawTooltip
  at com.droidvna.app.ui.chart.VnaChartKt.drawSmithCrosshair
```

The readout box (`|Γ| 0.045 ∠31°` / `VSWR 1.09`) is about 320 px wide, while the Smith drawing area on a small landscape screen is only about 278 px. The `coerceIn` that keeps the readout inside the drawing area therefore received an empty range ("upper bound < lower bound") and threw during drawing, crashing the whole app.

Fix: the readout's maximum width is clamped to the drawing area, and when the clamp range is invalid it falls back to left alignment. No chart size can produce an empty range anymore.

### Smith chart pinch zoom and two-finger pan did nothing

The old code skipped Smith mode entirely in the two-finger branch:

```kotlin
if (modeNow != ChartMode.SMITH) { /* zoom/pan */ }
```

So in Smith mode two fingers were recognized but did nothing, and the view was fixed to the full circle.

The Smith view now has its own viewport state (center Γ + window radius, `SmithView`):

- Pinch zoom **1×–50×**, two-finger drag to pan, with the content following the fingers;
- The grid is redrawn with zoom (resistance circles / reactance circles / real-axis labels are all recomputed for the viewport);
- Panning is bounded so the Γ=0 center cannot be dragged off-screen;
- Double-tapping the chart or the "Reset" button returns to the full circle;
- Traces and markers map to the new viewport and are clipped to the chart frame.

### The Smith chart was too small

`smithBounds` reserved a fixed 48 dp margin, shrinking the chart to about 278 px on small landscape screens. It now keeps a proportional margin (from 12 dp, about 6%), making the chart noticeably larger at every size.

## Changes

### Top-right button

That icon (`CenterFocusStrong`) has always been **reset view**, not fullscreen. It looked like it "never worked" because:

1. It is a reset action, so it only has something to do after the view has been zoomed;
2. Smith mode was previously locked to the full circle, so pressing it there could never change anything;
3. The button color was fixed gray, so even a successful reset was invisible.

Now: the button turns the theme's cyan when the view is away from default and returns to gray after reset; in Smith mode its accessibility label is "Reset Smith chart"; while zoomed, a `×N` multiplier label is shown in the top-right corner.

## New

### Trace frequency slider

Tapping a thin trace precisely on the Smith chart is hard, especially on a small screen. Now, whenever a marker exists, the bottom of the chart shows:

```
M1  trace frequency ────────●──────── 1.4188 GHz
```

- Drag the slider to move the selected marker along the sweep, snapping to the nearest measured point;
- Tap a marker card at the bottom to select it; the selected card is highlighted and determines which marker the slider controls;
- Press and drag a marker on the chart and it follows your finger, snapping to the nearest trace point by screen distance.
