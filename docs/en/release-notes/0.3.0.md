# LibreVNA Mobile 0.3.0

> [中文版](../../release-notes/0.3.0.md)

First public release: real-time two-port measurements, touch charts, SOL calibration, and export for Android tablets and phones.

## Highlights

- **Native USB Host, no PC**: access the VNA's vendor-specific bulk endpoints directly over OTG, protocol v14.
- **Real-time two-port sweeps**: S11 / S21 / S12 / S22, progressive points at low IFBW, ring-buffer refresh.
- **Touch-first chart**: pinch zoom/pan, crosshair, draggable markers, peak/valley, dB/phase/VSWR/Smith.
- **1-port SOL + THRU**: saved per device serial and still active after a restart.
- **LibreVNA-GUI `.cal` import**: supports Touchstone and parametric calkits, rebuilds SOL + THRU and applies it immediately.
- **LibreCAL / ECB-60 electronic calibration**: reads coefficients over USB SCPI, shows temperature/stability, and completes 2-port SOL + THRU automatically.
- **Export**: Touchstone `.s2p` / `.s1p`, CSV, saved to `Download/LibreVNA` or shared through the system.
- **Demo mode**: experience the full calibration flow without hardware.

## Installation

```bash
adb install -r LibreVNA-Mobile-0.3.0-debug.apk
```

- Requires Android 8.0 (API 26) or newer with USB Host / OTG.
- The APK is debug-signed, for testing only; use your own release keystore for official distribution.
- SHA-256: `403AFC857E5156A87FE0DB7FCBC0B707CCBA157642289674E41460D6AC282357`

If Xiaomi/HyperOS reports `INSTALL_FAILED_USER_RESTRICTED`, use:

```bash
adb push LibreVNA-Mobile-0.3.0-debug.apk /data/local/tmp/librevna.apk
adb shell pm install -r -t /data/local/tmp/librevna.apk
```

## Verified

- Xiaomi Pad (Android 17) + Harogic B60 (FW 1.8.6): a 401-point / 75 kHz continuous sweep runs at about 19–20 sweeps/s; progressive drawing and ring-buffer updates work at 15 Hz / 101 points and 1 kHz / 401 points.
- Harogic ECB-60 (FW 0.3.2): FACTORY coefficient loading, automatic 2-port SOL + THRU, and CAL take effect.
- Real `.cal` files exported by VNStudio: both Touchstone and purely parametric calkit paths import successfully.
- All 21 JVM unit tests pass.

## Known limitations

- The calibration model is 1-port SOL + THRU and does not include the full 12-term two-port SOLT error terms; `.cal` import and automatic E-Cal calibration use the same subset.
- E-Cal uses a fixed VNA P1/P2 ↔ Cal P1/P2 mapping and needs an externally powered OTG hub.
- Firmware update, signal generator, spectrum analysis, SCPI server, and standalone Touchstone calibration-kit import are not implemented.
- The chart is not performance-optimized beyond 1001 points.
- LibreVNA's own hardware has not been tested yet.

Full details are in the repository [README](../../../README.en.md) and [CHANGELOG](../../../CHANGELOG.md).
