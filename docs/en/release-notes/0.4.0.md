# LibreVNA Mobile 0.4.0

> [中文版](../../release-notes/0.4.0.md)

Bilingual UI, App settings, and more flexible chart control.

## Highlights

- **Chinese / English UI**: top-right gear → "App settings" → "Interface language" offers Follow system / Chinese / English; switching takes effect immediately and persists.
- **App settings panel**: language and About information (version, protocol, supported devices, GPL-3.0, upstream project) in one place.
- **Trace settings panel**: opened from above the chart or the gear on the "Trace" card; the first item is the **log frequency axis** (1-2-5 ticks), the setting persists, and future trace options will be added here.
- **Y-axis auto / manual**: new `Y auto` / `Y manual` toggle above the chart; one tap restores autoscale after manual zoom.
- Pinch zoom, pan, crosshair, and markers on the chart's X axis all support the log frequency axis.

## Installation

```bash
adb install -r LibreVNA-Mobile-0.4.0-debug.apk
```

- Requires Android 8.0 (API 26) or newer with USB Host / OTG.
- The APK is debug-signed, for testing only; use your own release keystore for official distribution.
- Size: 16,845,011 bytes
- SHA-256: `4272B311C04CA948793525C606C6AD3896E060E802E81902A0FE70F7828A1705`

If Xiaomi/HyperOS reports `INSTALL_FAILED_USER_RESTRICTED`, use:

```bash
adb push LibreVNA-Mobile-0.4.0-debug.apk /data/local/tmp/librevna.apk
adb shell pm install -r -t /data/local/tmp/librevna.apk
```

## Verified

- Xiaomi Pad (Android 17) + Harogic B60 (FW 1.8.6): Chinese/English switching takes effect immediately and survives force-stop and reinstall; App settings, About, and Trace settings panels work; the log axis over 500 MHz – 3 GHz shows 500M / 1G / 2G / 3G; Y auto / Y manual toggle both ways.
- The measurement page, calibration status, device page, sweep settings, and export page all show English copy.
- All 21 JVM unit tests pass.

## Known limitations

- English translations cover the main UI and common messages; a few low-level device/protocol log lines may remain in Chinese.
- Calibration is still 1-port SOL + THRU and does not include the full 12-term two-port SOLT error terms.
- The APK in the repository is debug-signed.

> **0.4.1 correction**: 0.4.0's E-Cal two-port measurement switched standards port by port, leaving the other port on NONE/the previous standard and producing spurs on the Smith chart. This was fixed in 0.4.1 with LibreVNA-GUI's all-port flow; use 0.4.1.
